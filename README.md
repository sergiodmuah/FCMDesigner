FCM Designer (Python)
======================
Versión en Python de FCM Designer para diseñar, simular y entrenar mapas cognitivos difusos.

**Instalación**
```bash
pip install -r requirements.txt
```

**Ejecución**
```bash
python main.py
```

**Funciones**
- Edición visual de mapas FCM/DFCM.
- Inferencia con varios tipos de normalización.
- Aprendizaje de pesos con PSO usando CSV/Excel (última columna = objetivo).
- Evaluación con MSE y métricas de clasificación.
